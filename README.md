# macdowsOS

[macdowsOS Tool UI](https://github.com/aiboqiao6/macdowsOS-Tool)  基于 C++/QT 的全自动 Windows 仿 macOS 集成工具

[macdowsOS Widget](https://github.com/aiboqiao6/macdowsOS-Widget) 基于 C++/QML 的仿 macOS 桌面小组件

[macdowsOS Files](https://github.com/aiboqiao6/macdowsOS-Files) 基于 Qt 的仿 macOS 文件管理器

[macdowsOS WindowChanger](https://github.com/aiboqiao6/macdowsOS-WindowChanger) 适用于Windows的仿macOS通用窗口样式注入框架
